# EZE OS Wallpapers

Place your wallpaper images here:
- desktop.jpg     (1920x1080 or higher — used as desktop wallpaper)
- lockscreen.jpg  (1920x1080 or higher — used as lock screen wallpaper)

These files are copied to: %SystemRoot%\Web\Wallpaper\EZE-OS\

Recommended:
- Format: JPG or PNG
- Resolution: 1920x1080 minimum
- File size: under 5MB each
