## 🚀 Overview

**EZE OS** is an optimized Windows Playbook for [AME Wizard](https://ameliorated.io) designed to transform stock Windows 10 and Windows 11 into a clean, fast, private, and distraction-free operating system. 

EZE OS balances **maximum privacy & performance** with **essential daily productivity features** needed for academic and office work (Microsoft Store, printing, accessibility, and .NET runtime support remain intact).

📖 **Complete Specification:** For full technical details, registry tweaks, debloating tables, and architecture breakdown, read the **[Technical Specification & Feature Reference](DOCUMENTATION.md)**.

---

## ✨ Features

- 🧹 **Comprehensive Debloating:** Removes pre-installed bloatware including OneDrive, Copilot/Recall AI, Microsoft Edge, Teams, and non-essential AppX packages.
- 🔒 **Privacy & Telemetry Stripping:** Disables Microsoft tracking services, CEIP diagnostic tasks, feedback prompts, and error reporting uploaders.
- 🌐 **Choice of Privacy Browsers:** Select during installation between **Brave Browser** (default), **Mozilla Firefox**, or **LibreWolf**.
- 💼 **Productivity Office Suites:** Choose between **LibreOffice** or **OnlyOffice Desktop** for native `.docx`, `.xlsx`, and `.pptx` compatibility.
- 🛠️ **Curated Productivity Tools:** Optional 1-click installation of **Thunderbird** (email/calendar), **VLC Media Player**, **7-Zip**, and **Notepad++**.
- ⚡ **System & Power Tweaks:** Automated `powercfg` hibernation controls (reclaims 2 GB – 8 GB+ disk space), Intel TSX optimization, and fast boot policies.
- 🎨 **Visual Styling:** Includes custom EZE OS metallic dark desktop and lock screen wallpapers, dark mode integration, and legacy right-click context menu.
- 🛡️ **Flexible Defender Choice:** Keeps **Windows Defender ENABLED by default** for student security, with an optional toggle to disable for advanced power users.

## 📥 How to Install

### Requirements
1. **Windows Updates:** Ensure all pending Windows updates are installed prior to running.
2. **Antivirus:** Uninstall third-party antivirus software (Windows Defender is supported).
3. **Power:** Ensure your computer is plugged into AC power.
4. **Internet:** Active internet connection is required for software package downloads.

### Step-by-Step Installation
1. Download the latest **AME Wizard** from [ameliorated.io](https://ameliorated.io).
2. Download the **`EZE-OS.apbx`** file from the [Releases](https://github.com/BaskaranElilan/EZE-OS/releases) page.
3. Launch `AME Wizard.exe` and drag & drop the `EZE-OS.apbx` file into the window.
4. Enter the Playbook password when prompted: `malte`
5. Customise your options (Browser, Office Suite, Defender, Hibernation, Apps).
6. Click **Next** and let EZE OS apply changes (~15–20 minutes). Restart when prompted.
